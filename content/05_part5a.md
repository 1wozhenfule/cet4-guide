# 第五部分　翻译高频考点

## 5.1 评分标准与四步翻译法

翻译 106.5 分（15 分制），30 分钟，汉译英一段 140—160 字。评分只看两件事：**信息是否译全、表达是否通顺**。

| 分数档 | 典型特征 |
| --- | --- |
| 13—15 分 | 信息完整，语法正确，用词恰当，句式有变化 |
| 10—12 分 | 信息基本完整，个别语法或词汇错误，表达可读 |
| 7—9 分 | 译出大意，漏译较多，语法错误明显但能猜懂 |
| 4—6 分 | 只译出部分信息，错误密集，理解困难 |
| 1—3 分 | 大量空白或几乎无法理解 |

**四步翻译法**：

1. **通读断句（3 分钟）。** 读完整段，用斜线把长句切成"一个主语 + 一个谓语"的小块。
2. **找主干、定谓语（2 分钟）。** 每块先确定"谁 + 做什么"，谓语动词是时态的唯一载体。
3. **逐句翻译（20 分钟）。** 先写主谓宾，再补定语、状语。不会的词用简单词替代，不要空着。
4. **检查（5 分钟）。** 时态、单复数、冠词、拼写、大小写、标点。

**三条原则**：

- **准确优先于华丽。** 一个正确的主谓宾，胜过三个错误的从句。
- **简单句优先于复杂句。** 长句拆成两三个短句，分数不会低；硬写长句出错，直接掉档。
- **会写的词优先。** 不会 "magnificent"，就写 "very beautiful"；不会 "symbolize"，就写 "is a symbol of"。

## 5.2 常考话题与命题规律

四级翻译是一段介绍性说明文，主题集中在"中国文化"和"中国发展"两大类。

| 话题 | 常见内容 | 高频表达 |
| --- | --- | --- |
| 传统节日 | 春节、端午、中秋的习俗与寓意 | falls on, family reunion, in memory of, symbolize |
| 饮食文化 | 八大菜系、饺子、茶、酒 | be famous for, be made of, date back to |
| 传统艺术 | 书法、京剧、剪纸、刺绣、瓷器 | be regarded as, be passed down, craftsmanship |
| 建筑园林 | 长城、故宫、四合院、苏州园林 | be located in, cover an area of, be listed as |
| 中医养生 | 针灸、草药、气功、阴阳 | traditional Chinese medicine, acupuncture, herbal |
| 历史地理 | 朝代、丝绸之路、长江黄河 | date back to, stretch across, originate from |
| 科技发展 | 高铁、移动支付、5G、航天 | high-speed rail, mobile payment, rank among |
| 社会民生 | 脱贫、乡村振兴、老龄化、环保 | poverty alleviation, aging population, improve |
| 教育文化 | 科举、书院、义务教育、高考 | compulsory education, college entrance examination |
| 城市生活 | 共享单车、外卖、快递、垃圾分类 | shared bikes, food delivery, garbage sorting |

**命题规律**：4—6 句，每句 20—40 字；常含时间（建于、始于）、地点（位于）、数字（占、达到）、因果（因此、使得）、评价（被誉为、象征）。翻译时先把这些"信息点"圈出来，译全就是基础分。
