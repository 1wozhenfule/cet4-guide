| farther / further | farther 距离；further 程度、进一步 | farther away / further study |
| lay / lie | lay 放置（及物）；lie 躺（不及物） | lay the book down / lie on the bed |
| lose / loose | lose 丢失；loose 松的 | lose the key / a loose shirt |
| maybe / may be | maybe 副词"也许"；may be 情态动词 + be | Maybe he is right. / He may be right. |
| precede / proceed | precede 在……之前；proceed 继续进行 | precede the meeting / proceed with the plan |
| imply / infer | imply 说话人暗示；infer 听者推断 | What do you imply? / We can infer that… |
| industrial / industrious | industrial 工业的；industrious 勤奋的 | industrial waste / an industrious student |
| credible / credulous | credible 可信的；credulous 轻信的 | credible evidence / a credulous person |
| expect / except | expect 期待；except 除……之外 | expect to win / everyone except Tom |
