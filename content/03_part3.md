# 第三部分　听力高频考点

## 3.1 语音现象与"听不清"的真相

很多同学说"单词都认识，连起来就听不懂"。原因通常不是词汇量，而是五个语音现象。

| 现象 | 规则 | 例子 |
| --- | --- | --- |
| 连读 | 前词以辅音结尾、后词以元音开头，连起来读 | not at all → /nɒtətɔːl/；take it easy → /teɪkɪˈtiːzi/ |
| 失去爆破 | 两个爆破音相邻，前一个只做口型不发音 | next day；big problem；Good morning |
| 弱读 | 虚词在句中读得很轻 | and → /ən/；of → /əv/；to → /tə/；for → /fə/；can → /kən/ |
| 同化 | 相邻音互相影响，变成第三个音 | don't you → /dəʊntʃu/；would you → /wʊdʒu/；did you → /dɪdʒu/ |
| 美音特征 | r 音卷舌、短音 /ɑː/、t 的闪音 | car、hard、water（/ˈwɔːtər/）、better（/ˈbedər/） |

还有一个高频失分点是**数字混淆**：thirteen 重音在后、元音长；thirty 重音在前、结尾是短促的 /i/。fourteen / forty、fifteen / fifty、sixteen / sixty 同理。听到数字时，先判断重音位置。

## 3.2 短篇新闻：倒金字塔与高频词

短篇新闻 3 篇、7 题，语速偏快，但结构极其固定：**导语（第一句）→ 细节展开 → 背景或引述**。导语一定包含"谁、在哪、发生了什么"，主旨题答案就在第一句。

**三条技巧**：

1. 第一句必须听懂。哪怕后面全乱，主旨题也能拿到。
2. 数字、地点、伤亡、原因是细节题的重灾区，边听边在选项旁记符号（↑↓、数字、地名首字母）。
3. 听到 however、but、officials say、according to 要立刻警觉，后面常是原因或转折。

**新闻高频词**：

| 类别 | 高频词 |
| --- | --- |
| 灾难事故 | earthquake, flood, drought, hurricane, typhoon, landslide, wildfire, casualty, death toll, evacuate, rescue, survivor, collapse, damage |
| 政治外交 | election, vote, campaign, candidate, policy, reform, legislation, parliament, congress, summit, treaty, sanctions, protest, demonstration |
| 经济商业 | inflation, recession, unemployment, GDP, budget, deficit, tariff, stock market, investment, currency, merger, bankruptcy |
| 科技医疗 | breakthrough, launch, satellite, vaccine, clinical trial, cybersecurity, data breach, outbreak, symptom, treatment |
| 社会民生 | strike, immigration, housing, healthcare, education reform, welfare, pension, inequality |
| 犯罪司法 | arrest, suspect, sentence, trial, investigation, fraud, smuggling, theft, witness, verdict |

**新闻常考的四个方向**：发生了什么（主旨）、造成什么后果（伤亡/损失）、原因是什么（天气/人为/政策）、各方怎么回应（官员/居民/专家）。

## 3.3 长对话：问答结构与场景词

长对话 2 篇、8 题，一男一女，围绕一件事来回讨论。它的答案分布有很强的规律：

- **答案多在回答方**。第一个人提问，第二个人回答，考点几乎都落在第二个人的话里。
- **第二回合之后才出真答案**。开头的寒暄（How are you? / Nice day, isn't it?）不考。
- **转折词后面是答案**：but、actually、to be honest、the problem is。
- **建议句后面是答案**：Why not …? / You'd better … / Have you tried …?

**长对话的六种题型**：原因（Why…）、建议（What does the man suggest?）、态度（How does the woman feel?）、地点（Where…）、关系（What's the relationship?）、下一步（What will the man do next?）。

**人物关系判断**靠三样东西：称呼（Professor / Mr. / honey）、语气（客气/随意/命令）、场景词（menu / prescription / lease）。常见关系：师生、同学、同事、医患、房东与租客、店员与顾客、面试官与应聘者。

## 3.4 听力篇章：结构与信号词

听力篇章 3 篇、10 题，每题 14.2 分。文章通常是说明文或议论文，结构只有三种：

- **总分总**：首段提出现象或观点，中间分两三点说明，结尾总结。
- **问题—解决**：提出问题 → 分析原因 → 给出办法。
- **时间顺序**：介绍人物生平、事件经过、事物发展。

**听篇章的正确姿势**：不要试图记住每一句，只记"骨架"——首段主题、每个分论点的第一句、结尾的结论。题目按顺序出，听到哪做到哪，不要回头纠结。

**信号词就是段落的路标**：

| 功能 | 信号词 |
| --- | --- |
| 提出主题 | Today we'll talk about / The topic of today's lecture is |
| 分点 | First / Second / Another / Besides / Moreover |
| 举例 | For example / For instance / Take … as an example |
| 转折 | But / However / Yet / On the contrary |
| 因果 | Because / So / Therefore / As a result |
| 强调 | The key point is / What's important is / Remember that |
| 结论 | In conclusion / To sum up / The bottom line is |

## 3.8 数字、时间、价格与计算

数字题在听力里占的分不多，但一旦出现就是"送分或送命"。

| 类型 | 读法/写法 |
| --- | --- |
| 钟点 | 8:15 a quarter past eight；8:45 a quarter to nine；9:30 half past nine；9:50 ten to ten |
| 日期 | March 5th / the fifth of March；1990s（nineteen nineties） |
| 价格 | $12.50 twelve fifty / twelve dollars and fifty cents；£3.99 three ninety-nine |
| 大数 | 1,500 fifteen hundred；2,000,000 two million；3.5 billion |
| 分数 | 1/3 one third；3/4 three quarters；2/5 two fifths |
| 百分比 | 15% fifteen percent；0.5% zero point five percent |
| 温度 | minus five degrees；30 degrees Celsius |
| 电话 | 读单个数字，0 读作 oh 或 zero |

**计算题关键词**：total（总计）、altogether（总共）、each（每个）、per person（每人）、discount（折扣）、20% off（打八折）、double（两倍）、twice（两次/两倍）、half（一半）、a quarter（四分之一）、dozen（一打）、a couple of（几个/两个）。

注意"打折"的表达：20% off 是"减价 20%"，即打八折；中文说"打八折"，英文说 20% discount 或 20% off，不要写成 80% discount。

## 3.9 没听懂时的补救与蒙题策略

听力只播一遍，“回头再听”是不可能的。没听懂时按顺序处理：

1. **立刻放弃，预读下一题。** 丢一题最多 7.1 分，丢三题就是 21 分。
2. **抓重复词和语气。** 反复出现的词往往是主题，语气突变往往是态度。
3. **用选项差异反推。** 四个选项都在说“时间”，就回去听数字。
4. **蒙题优先级**：含同义替换的选项 > 表述温和的选项（may, probably）> 具体细节的选项；含 all、never、only、must 的优先排除。
5. **态度题**选“理解、支持、略微担心”的一项；新闻的态度通常中立。
6. **涂卡节奏**：做完一题点一下，不要攒到最后。

**记住**：听力分数不取决于“听懂多少”，而取决于“错过一题后能否立刻恢复”。
