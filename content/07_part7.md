# 第七部分　语法与搭配速查

## 7.1 时态与语态

| 时态 | 构成 | 典型用法 | 例句 |
| --- | --- | --- | --- |
| 一般现在时 | do / does | 事实、习惯、普遍真理 | He works in a bank. |
| 一般过去时 | did | 过去发生的事 | He worked there in 2010. |
| 一般将来时 | will do / be going to do | 将来的事 | He will work here next year. |
| 现在进行时 | am/is/are doing | 此刻正在进行 | He is working now. |
| 过去进行时 | was/were doing | 过去某时正在进行 | He was working at eight last night. |
| 将来进行时 | will be doing | 将来某时正在进行 | He will be working at eight tomorrow. |
| 现在完成时 | have/has done | 过去动作对现在的影响 | He has worked here for five years. |
| 过去完成时 | had done | 过去的过去 | He had worked there before he moved. |
| 将来完成时 | will have done | 将来某时前完成 | By 2030, he will have worked here for 20 years. |
| 现在完成进行时 | have/has been doing | 从过去持续到现在 | He has been working all day. |
| 被动语态 | be + done | 强调承受者 | The bridge was built in 1990. |

**写作与翻译最常用的四个时态**：介绍现状用一般现在时；介绍历史用一般过去时；介绍发展变化用现在完成时；提出建议用 should + 动词原形。时态一旦确定，全段统一，不要来回跳。

## 7.2 非谓语动词

| 形式 | 核心含义 | 功能 | 例句 |
| --- | --- | --- | --- |
| to do | 目的、将来、具体动作 | 主语、宾语、目的状语、结果状语 | I went there to buy books. |
| doing | 主动、进行、伴随 | 主语、宾语、定语、状语 | Seeing the teacher, he ran away. |
| done | 被动、完成 | 定语、状语、补语 | Built in 1990, the bridge is still in use. |

**接 to do 与 doing 意思不同的动词**：

| 动词 | + to do | + doing |
| --- | --- | --- |
| remember | 记得去做（还没做） | 记得做过（已做） |
| forget | 忘记去做 | 忘记做过 |
| regret | 遗憾要去做 | 后悔做过 |
| stop | 停下来去做另一件事 | 停止做某事 |
| try | 努力去做 | 试着做做看 |
| mean | 打算做 | 意味着 |
| go on | 接着做另一件事 | 继续做同一件事 |
| need | 需要去做 | 需要被做（= to be done） |

**三条判断规则**：① 主语与非谓语是主动关系用 doing，被动关系用 done；② 表示目的用 to do；③ 表示已经完成用 having done。

## 7.3 定语从句

| 先行词 | 关系代词 | 例句 |
| --- | --- | --- |
| 人 | who / whom / that | The man who helped me is a doctor. |
| 物 | which / that | The book which I bought is useful. |
| 人或物（所属） | whose | The girl whose father is a teacher studies hard. |
| 时间 | when | I still remember the day when we met. |
| 地点 | where | This is the house where he lived. |
| 原因 | why | That is the reason why he left. |

**只用 that 不用 which 的四种情况**：

1. 先行词是 all、everything、nothing、anything、little、much 等不定代词。
2. 先行词被序数词或最高级修饰（the first、the best）。
3. 先行词既有人又有物。
4. 主句以 who 或 which 开头。

**介词 + which/whom**：The city in which I grew up has changed a lot.

**非限制性定语从句**：用逗号隔开，which 可以指代前面整句话。He passed the exam, which surprised everyone.

## 7.4 名词性从句

| 类型 | 引导词 | 例句 |
| --- | --- | --- |
| 主语从句 | that / whether / what / who | What he said is true. |
| 宾语从句 | that / whether / if / what | I don't know whether he will come. |
| 表语从句 | that / whether / because | The reason is that he was ill. |
| 同位语从句 | that / whether | The fact that he lied shocked us. |

**三条铁律**：① 所有名词性从句都用**陈述语序**（主语在前，谓语在后）；② that 在宾语从句中可省略，在主语、表语、同位语从句中不可省；③ whether 可以引导所有名词性从句，if 只能引导宾语从句。

## 7.5 状语从句

| 类型 | 常用连词 | 例句 |
| --- | --- | --- |
| 时间 | when, while, as, before, after, since, until, as soon as | As soon as he arrived, it began to rain. |
| 条件 | if, unless, as long as, provided that | You will fail unless you work harder. |
| 原因 | because, since, as, now that | Since you are here, let's start. |
| 结果 | so … that, such … that | He was so tired that he fell asleep. |
| 目的 | so that, in order that | Speak louder so that everyone can hear. |
| 让步 | although, though, even if, while, no matter how | Although it was late, he kept working. |
| 比较 | as … as, than | She runs faster than I do. |
| 方式 | as if, as though | He acted as if nothing had happened. |
| 地点 | where, wherever | Where there is a will, there is a way. |

**注意**：although 与 but 不能连用；because 与 so 不能连用；while 既可表"当……时"，也可表"然而"（对比）。

## 7.6 虚拟语气

| 时间 | 从句 | 主句 |
| --- | --- | --- |
| 与现在相反 | did / were | would / could / might do |
| 与过去相反 | had done | would / could / might have done |
| 与将来相反 | did / were to do / should do | would / could do |

例句：If I were you, I would accept the offer.（现在）／ If he had left earlier, he would have caught the train.（过去）／ If it should rain tomorrow, we would stay at home.（将来）

**特殊句型**：

- wish：I wish I had studied harder.（后悔）
- as if：He talks as if he knew everything.
- would rather：I would rather you didn't go.
- It is (high) time that：It is high time that we took action.（用过去式）
- 建议、要求、命令类动词后的从句用 (should) do：suggest, advise, demand, require, insist, order, propose。
- 省略 if 的倒装：Had I known, I would have told you. / Were I you, I would go.

## 7.7 倒装、强调与省略

**倒装的五种情况**：

1. 否定词放句首：Never have I seen such a beautiful place.
2. only + 状语放句首：Only in this way can we succeed.
3. so / neither 开头：He likes tea, and so do I. / She can't swim, neither can I.
4. 地点状语放句首（完全倒装）：On the top of the hill stands a temple.
5. 虚拟条件句省略 if：Had I known the truth, I would have acted differently.

**强调句**：It is/was + 被强调部分 + that/who + 其余部分。判断方法：去掉 It is 和 that，句子仍然完整。

**省略**：状语从句中主语与主句一致时可省略主语和 be 动词。When (he was) asked, he said nothing.

## 7.8 主谓一致与比较结构

**主谓一致十条规则**：

1. 单数主语配单数谓语，复数主语配复数谓语。
2. 集合名词（family、team、government）作整体时用单数，强调成员时用复数。
3. each、every、either、neither、everyone、something 作主语，谓语用单数。
4. 就近原则：either … or、neither … nor、not only … but also、there be 的谓语与最近的主语一致。
5. 就远原则：as well as、together with、along with、besides、except、rather than 不影响前面的主语。
6. 不定式、动名词、从句作主语，谓语用单数。
7. the number of + 复数名词，谓语用单数；a number of + 复数名词，谓语用复数。
8. 时间、金钱、距离的复数视为整体，谓语用单数（Ten years is a long time）。
9. 以 -s 结尾的学科、疾病名（physics、news、measles）作主语，谓语用单数。
10. many a + 单数名词、more than one + 单数名词，谓语用单数。

**比较结构**：as … as（原级）、not as … as（不如）、more … than（比较级）、the more … the more（越……越……）、倍数表达（three times as large as）、superior to / inferior to（本身含比较，不加 than）。
