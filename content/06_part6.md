## 6.6 常见前缀、后缀与构词

构词法是阅读里的猜词工具：先拆前缀和后缀，判断词性与大致方向（否定？名词？形容词？），再回到句子里排除选项。

**前缀**

| 前缀 | 含义 | 例词 |
| --- | --- | --- |
| un- | 否定 | unhappy, unfair, unable |
| in- / im- / ir- / il- | 否定 | incorrect, impossible, irregular, illegal |
| dis- | 否定、相反 | disagree, disappear, dishonest |
| non- | 非 | nonstop, nonprofit |
| re- | 再、重新 | review, rebuild, recycle |
| pre- | 之前 | predict, prevent, preschool |
| post- | 之后 | postwar, postpone |
| over- | 过度 | overwork, overestimate |
| under- | 不足、在下 | underestimate, underground |
| sub- | 在下、次级 | subway, subtitle |
| super- | 超过 | supermarket, supervise |
| inter- | 之间 | international, interact |
| trans- | 跨越 | transport, transform |
| anti- | 反对 | antibiotic, antisocial |
| co- | 共同 | cooperate, coexist |
| multi- | 多 | multimedia, multicultural |
| auto- | 自动、自己 | automatic, autobiography |
| bio- | 生命 | biology, biodiversity |
| micro- | 微小 | microwave, microscope |
| tele- | 远 | telephone, telescope |

**后缀**

| 后缀 | 词性 | 例词 |
| --- | --- | --- |
| -tion / -sion | 名词 | education, decision |
| -ment | 名词 | development, agreement |
| -ness | 名词 | happiness, awareness |
| -ity | 名词 | ability, diversity |
| -ance / -ence | 名词 | importance, difference |
| -ship | 名词 | friendship, leadership |
| -hood | 名词 | childhood, neighborhood |
| -ism | 名词 | tourism, capitalism |
| -ist | 名词（人） | scientist, artist |
| -er / -or | 名词（人/物） | teacher, actor |
| -able / -ible | 形容词 | reliable, visible |
| -al | 形容词 | natural, cultural |
| -ive | 形容词 | active, effective |
| -ous | 形容词 | famous, dangerous |
| -ful | 形容词 | useful, powerful |
| -less | 形容词（无） | hopeless, endless |

> 构词法的价值在于"猜词"：阅读里遇到不认识的词，先拆前缀和后缀，判断词性和大致方向（否定？名词？形容词？），往往就能排除两个选项。
